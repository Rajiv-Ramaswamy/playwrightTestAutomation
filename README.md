# playwrightTestAutomation

This repository contains my Playwright Test Automation sample project Mocha framework with Cucumber BDD approach on top over it. This project has been developed using both JavaScript and as well as TypeScript.

Standalone Tests can be found here - standaloneTests/

End-To-End Tests with Page Object Model design pattern can be found here - tests/

Page Objects of Mocha Framework can be found here - pageObjects/

Reusable API util files can be found here - utils/

Page Objects in TypeScript - TS_pageObjects/

Reusable API util files of TypeScript can be found here - TS_utils/

Cucumber feature files - features/

Cucumber Step definition files - features/step_definitions/

Cucumber Hook functions - features/support
